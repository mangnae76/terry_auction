# 매매사업자 세금 매뉴얼 — 원고(목차·상세)

> 기반: 앱 매뉴얼 › 낙찰이후 › 세금 탭(과세 구조·세율표·비인정 경비·일정) + 외부 세무 자료 대조. 법조문은 최소화.
> 일반 정보이며 세무 자문이 아님. 기준일 2026. 11. 9.

## 세금 탭에서 바뀌거나 더한 것
| 항목 | 세금 탭 | 매뉴얼 |
|---|---|---|
| 신고 흐름 | 종소세(5월)만 | **매도 후 2개월 안 예정신고** → 5월 확정신고에서 정산 |
| 취득세 | 1주택 세율표 | 다주택 중과표 추가, 매매사업자 취득세 혜택 없음 |
| 면세·과세 | 없음 | 면세사업자 vs 일반과세자 비교표 신설 |

## 0. 요약
| 항목 | 내용 |
|---|---|
| 핵심 | 판 이익을 양도세가 아니라 **사업소득(종합소득세)** 으로 신고 |
| 이점 | 2년 안에 팔아도 단기 양도세율(70%·60%) 대신 **기본세율 6~45%** |
| 팔 때마다 | 매도일이 속한 달 말일부터 **2개월 안 예정신고** |
| 5월 | 한 해 매도분 합산해 **종합소득세 확정신고**, 이자 등 경비 반영 |
| 예외 | 서울 전역·경기 12곳(조정대상지역) 다주택 중과 주택은 양도세 방식과 비교해 큰 세액 |

## 1. 세금 지도
| 언제 | 세금 | 할 일 |
|---|---|---|
| 잔금 후 60일 안 | 취득세 | 신고·납부. 매매사업자도 일반과 같은 세율·중과 |
| 6월 1일 보유분 | 재산세(7·9월), 종부세(12월) | 고지서 납부. 재고 주택도 과세 |
| 매도 후 2개월 안 | 매매차익 예정신고 | 손해여도 신고, 지방소득세 함께 |
| 1·7월 / 2월 10일 | 부가세(과세사업자) / 사업장현황신고(면세사업자) | 사업자 유형별 |
| 다음 해 5월 | 종합소득세 확정신고 | 예정신고 낸 세금 빼고 정산 |

취득세율(2026년 현재)
| 구분 | 1주택 | 2주택 | 3주택 | 4주택 이상 |
|---|---|---|---|---|
| 조정대상지역 | 1~3% | 8% | 12% | 12% |
| 그 외 지역 | 1~3% | 1~3% | 8% | 12% |
- 1~3%: 6억 이하 1%, 6~9억 구간별, 9억 초과 3%. 비주택(상가·토지) 4%.

## 2. 면세사업자 vs 과세사업자
> **결론** — 85㎡ 이하 아파트·빌라만 하면 **면세사업자**가 간단하고 부담이 적다. 85㎡ 초과 주택·오피스텔·상가도 하면 **일반과세자**가 되고, 팔 때 건물분 부가세 10%를 계약서에 '별도'로 받아야 손해가 없다.

| 항목 | 면세사업자 | 일반과세자 |
|---|---|---|
| 대상 물건 | 전용 85㎡ 이하 주택만 | 85㎡ 초과 주택, 오피스텔, 상가 포함 |
| 경매로 살 때 부가세 | 없음 | 없음 (경매는 부가세 대상 거래 아님) |
| 팔 때 부가세 | 없음 | **건물분 10%** (토지분은 없음) |
| 수리비 부가세 | 돌려받지 못함(비용으로 처리) | 공제·환급 가능 |
| 발급 서류 | 계산서 | 세금계산서 |
| 정기 신고 | 사업장현황신고(2월 10일) | 부가세 신고(1·7월), 예정고지(4·10월) |
| 장점 | 신고 간단, 부가세 걱정 없음 | 수리비 부가세 환급, 오피스텔·상가 취급 |
| 단점 | 수리비 부가세 환급 불가 | 매수인에게 부가세를 못 받으면 매도가에서 10% 손해 |
| 맞는 사람 | 국민주택규모 아파트·빌라 위주 | 큰 평수·오피스텔·상가까지 |
- 간이과세는 고를 수 없음.

## 3. 팔 때 — 예정신고와 5월 정산
1. **예정신고(매도 후 2개월)**: 매매차익 = 매도가 − 낙찰가 − 취득세 등 취득비용 − 수리비(자본적 지출) − 중개수수료. 여기에 기본세율(6~45%). 기본공제 250만원 없음.
2. **5월 확정신고**: 한 해 매도분 + 다른 소득 합산. 예정신고 때 못 뺀 대출이자·재산세 등 경비 반영 → 예정신고 납부세액 빼고 정산(환급 나기도).

세액 예시 — 매매차익 5,000만원, 10개월 보유, 비조정 지역, 다른 소득 없음
| 구분 | 계산 | 세금(지방세 포함) |
|---|---|---|
| 일반 개인(양도세) | (5,000만 − 250만) × 70% | 약 **3,658만원** |
| 매매사업자(예정신고) | 5,000만 × 15% − 126만 | 약 **686만원** |
- 직장 소득 등 다른 소득이 있으면 5월 합산 때 세율 구간이 올라갈 수 있음.

종합소득세율(현행)
| 과세표준 | 세율 | 누진공제 |
|---|---|---|
| 1,400만 이하 | 6% | — |
| 1,400만~5,000만 | 15% | 126만 |
| 5,000만~8,800만 | 24% | 576만 |
| 8,800만~1.5억 | 35% | 1,544만 |
| 1.5억~3억 | 38% | 1,994만 |
| 3억~5억 | 40% | 2,594만 |
| 5억~10억 | 42% | 3,594만 |
| 10억 초과 | 45% | 6,594만 |

## 4. 경비
| 구분 | 항목 | 언제 반영 |
|---|---|---|
| 인정 | 낙찰가, 취득세·등기비·법무사비, 수리·인테리어(자본적 지출), 중개수수료 | 예정신고부터 |
| 인정 | 대출이자, 재산세·종부세, 소액 수선비, 사무 비용 | 5월 확정신고 |
| 조건부 | 명도 이사비 — 합의서·이체내역 있으면 인정 가능 / 입찰 조사비 — 낙찰 물건만 | 세무사 확인 |
| 불인정 | 전 소유자 미납관리비 대납, 보유 중 주거용 관리비, 소득세 자체, 벌금·가산세·연체료, 개인 경비 | 기록만 하고 신고에서 제외 |

## 5. 주의할 점
| 주의 | 내용 |
|---|---|
| 비교과세 | 조정대상지역(서울 전역·경기 12곳) 다주택 중과 주택, 비사업용 토지, 분양권, 미등기는 양도세 방식과 비교해 큰 세액. 다주택 중과는 2026. 5. 10.부터 다시 적용(2027~28년 완화는 정부안 단계) |
| 전입 금지 | 재고 주택에 본인·가족이 전입·거주하면 매매사업 재고로 인정 안 될 수 있음 |
| 사업성 | 반복 매매와 매도 노력(중개 의뢰·광고) 기록 보관. 사업성이 부정되면 양도세로 재계산 |
| 주택 수 | 1주택 비과세 판단 땐 재고 주택 제외, 중과·취득세 판단 땐 포함 |
| 건보료 | 피부양자는 사업소득이 생기면 자격을 잃을 수 있음. 직장인은 보수 외 소득 연 2,000만원 넘으면 추가 보험료 |

체크리스트(글자형)
- 매도 전: 비교과세 대상인지(지역·주택 수), 면세/과세, 계약서 '부가세 별도'(과세 물건)
- 매도 후: 2개월 안 예정신고, 지방소득세
- 연중: 증빙(세금계산서·카드·이체), 사업용 계좌·카드만 사용
- 5월: 종합소득세 확정신고, 이자·재산세 등 경비 반영
