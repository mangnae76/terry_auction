# 반셀프 인테리어로 수리비 절반 아끼기 — 원고(목차·상세)

> 바탕: 보내주신 자료(기술자 일당·철거·공사 순서) + 외부 조사(노임단가, 공사 순서, 관리사무소 신고, 폐기물 신고, 계약·하자). 기준일 2026. 11. 17.

## 0. 요약
| 항목 | 내용 |
|---|---|
| 방식 | 반셀프 — 자재와 기술자를 직접 구하고 일정은 내가 짠다 |
| 사례 | 59㎡ 아파트 업체 견적 약 2,200만원 → 반셀프 약 1,200만원(한국경제 2026. 9.) |
| 순서 | 철거 → 목공·화장실·전기(일정에 맞춰) → 시트지 → 도배 → 장판 → 입주 청소 |
| 철거 | 걸레받이·몰딩·강화마루는 직접, 문은 맡겨도 됨 |
| 사람 | 기술자는 일당으로. 자재값에 마진을 얹는 사람 말고 시공비만 받는 기술자 |
| 신고 | 관리사무소 공사 신고·동의서, 폐기물 배출 신고 |

## 1. 어디까지 고칠까
| 목적 | 범위 | 포인트 |
|---|---|---|
| 팔 집 | 도배·장판·조명·필름, 화장실은 상태 보고 | 밝게 보이는 곳에 돈을 쓴다 |
| 세 줄 집 | 고장 나는 곳 위주(수전·보일러·누수) + 도배·장판 | 오래 버티는 자재 |
| 구축(20년 이상) | 철거 뒤 배관·전기·누수부터 확인 | 숨은 하자 대비 예비비 |
- 내력벽 철거·발코니 확장은 행위허가 대상 → 반셀프 범위 밖.

## 2. 공사 순서
- 철거 먼저(1~2일).
- 목공(이틀 + 보조 1명) · 화장실(하루 넘게) · 전기(하루)는 일정에 맞춰 순서를 바꿔도 됨. 단, 배선·배관 위치를 옮기면 전기·설비를 목공보다 먼저.
- 싱크대·신발장은 화장실 뒤.
- 시트지(샷시·문틀) → 도배 → 장판은 순서 고정. 엉키면 마감이 상함.
- 입주 청소는 맨 마지막.

## 3. 철거
| 항목 | 맡기면 |
|---|---|
| 방문 철거 | 3만원/개 |
| 몰딩·걸레받이 | 10~15만원씩 |
| 바닥 | 30~40만원 (강마루는 평당 약 3만원) |
| 전체 | 100만원 초반 |
- 걸레받이·몰딩·강화마루는 직접(빠루로 몇 초). 문은 힘들면 맡기기 — 직접 뜯고 폐기만 맡기면 개당 4,000~5,000원.
- 강마루는 기계로 밀고 본드까지 떼야 해서 맡김.
- 강마루 위 장판 덧시공은 가능하지만 마루 이음선이 비침 → 원칙은 철거 후 시공.
- 몰딩을 떼면 벽지가 함께 뜯겨 도배 범위가 늘 수 있음.
- 철거비 아낀 돈: 걸레받이만 약 15만원, 몰딩·걸레받이 약 50만원, 할 수 있는 만큼 약 70~80만원.
- 폐기물: 5톤 미만은 '공사장 생활폐기물' — 구청 지정 불연성 마대(서울 20L)로 배출하거나 위탁, 배출 1~3일 전 신고(서울은 '빼기' 앱). 5톤 이상은 건설폐기물(구청 처리계획 신고). 마대 종류·색·신고 방법은 지역마다 다름.

## 4. 기술자는 일당으로
| 직종 | 일당(만원) | 메모 |
|---|---|---|
| 목수 | 약 45 | 혼자 가능, 보통 이틀 + 보조 1명 |
| 타일 기술자 | 30~40 | 화장실은 하루 넘게 |
| 목공 보조 | 25~28 | 목수 1명당 1명 |
| 전기 기사 | 20~25 | 18평 기준 하루 |
| 욕실 설치 | 20~25 | 변기·수전·수건걸이 |
| 철거·세팅 작업자 | 15~20 | 폐기물 비용 별도 |
- 참고: 2026. 9. 시중노임단가 도배공 229,833원, 타일공 294,379원, 보통인부 172,698원(기본급 성격이라 실제 일당과 다를 수 있음).
- 구하는 곳: 당근·숨고, 자재 매장 소개.
- 처음이면 화장실 같은 공정은 맡기고 옆에서 순서를 지켜보기. 다음부터 직접.

## 5. 신고·계약·돈
- 관리사무소: 공사 신고, 입주민 동의서(범위는 단지 규약), 공사 가능 시간·요일, 엘리베이터 보양, 큰 소음 날짜 안내.
- 계약: 1,500만원 이상 실내건축은 실내건축공사업 등록 업체. 기술자와도 작업 범위·일수·자재 포함 여부를 문자로 남기기. 하자: 실내 마감 1년, 창호·설비 2년(업체 공사 기준).
- 돈: 매매사업자면 수리비는 경비 — 이체·카드·세금계산서로 지급하고 영수증 보관. 인건비 원천징수 처리는 세무사 확인.

체크리스트(글자형): 공사 전 / 철거 날 / 공정 중 / 마감·정산
