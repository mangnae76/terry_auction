## 0. 한눈에 보기
| 항목 | 내용 |
|---|---|
| 무엇 | 낙찰받은 집에서 점유자를 내보내고 집을 넘겨받는 일 |
| 법적 수단 | 인도명령(민사집행법 제136조) → 강제집행(제258조) |
| 신청 시점 | **잔금 납부와 동시에** 인도명령 신청 |
| 마감 | 잔금 납부 후 **6개월**. 넘기면 명도소송(판결까지 7~8개월 이상) |
| 현실 | 대부분 협상으로 끝남. 강제집행 계고 단계에서 상당수 합의 |
| 금지 | 잠긴 문을 임의로 열기 → 주거침입·재물손괴 위험 |

## 1. 명도란
- 소유권은 잔금 납부로 넘어오지만, 집 안의 사람과 짐은 자동으로 나가지 않음.
- 점유자를 내보내는 법적 통로는 둘: ① 인도명령(결정, 빠름) ② 명도소송(판결, 느림).
- 비유: 중고차를 샀는데 전 주인이 아직 운전석에 앉아 있는 상황. 명의는 내 것이지만 열쇠는 따로 받아야 함.

## 2. 명도 일정
〔그림〕 낙찰 → (1주) 매각허가결정 → (확정 후 1월 안) 잔금 납부 + 인도명령 신청 → (약 1~2주) 결정·송달 → 강제집행 신청 → 계고 → (약 2주) 본집행

| 구간 | 할 일 | 핵심 |
|---|---|---|
| 낙찰 당일 | 관리사무소 방문(미납관리비 확인), 세대 방문·메모 남기기 | 아직 소유자 아님. 내용증명 불필요 |
| 잔금 납부 전 | 연락 기다리기, 대화만 | 협상 마감 = 잔금 납부일로 설정 |
| 잔금 납부 일 | 인도명령 신청(법무사에 등기와 함께 의뢰 가능) | 6개월 기한 시작 |
| 결정·송달 | 결정문이 쌍방에 송달(약 1~2주) | 송달 안 되면 특별·공시송달로 1~2개월 추가 |
| 강제집행 | 신청 → 계고 → 본집행 | 계고 후 약 2주 뒤 본집행(실무) |

## 3. 점유자 유형별 대응
| 점유자 | 인도명령 | 심문 | 대응 포인트 |
|---|---|---|---|
| 채무자·소유자(가족·직원 포함) | 가능 | 없음 | 가장 빠름. 가족·직원은 점유보조자로 함께 집행 |
| 대항력 없는 임차인(배당 받음) | 가능 | 원칙적 심문 | 명도확인서 = 배당금 수령 열쇠. 협상 쉬움 |
| 대항력 없는 임차인(배당 못 받음) | 가능 | 원칙적 심문 | 이사비 요구 가능성 큼. 협상 + 인도명령 병행 |
| 대항력 있는 임차인 | **불가** | — | 보증금 인수 대상. 전액 배당 시 배당표 확정 후 인도 |
| 유치권 주장자 | 압류 후 점유면 가능 | 심문 | 성립·대항력 다툼은 소송까지 갈 수 있음 |
| 정체 모를 제3자 | 가능(대항 권원 없을 때) | 심문 | 현황조사서·전입세대열람으로 이름 확인, 점유이전금지가처분 |

- 매수인은 상대방의 '점유'만 증명하면 됨. 대항 권원은 점유자가 증명(2015마2025).

| 대법원 2005.8.19. 2005다22688 | 압류 후 점유를 얻은 유치권 | 매수인에게 **대항 불가** |
| 대법원 2011.11.24. 2009다19246 | 가압류 후·압류 전 점유를 얻은 유치권 | 매수인에게 **대항 가능** |
| 대법원 2000.1.5. 99마4307 | 무상거주(임차인 아님) 확인서를 써 준 사람 | 나중에 임차인이라며 인도명령 다툴 수 없음(신의칙) |
| 대법원 1997.8.29. 97다11195 | 대항력+우선변제권 임차인이 배당요구 | 배당표 확정까지 인도 거절 가능 |
| 대법원 2001.9.20. 2001다8677(전합) | 전 소유자 미납관리비 | 매수인은 **공용부분만** 승계 |
| 대법원 2006.6.29. 2004다3598 | 미납관리비 연체료 | 연체료는 승계 안 함 |
| 대법원 2018.10.15. 2018그612 | 집행 현장에 남긴 짐(목적외 동산) | 채무자가 안 찾아가면 보관 여부와 관계없이 법원 허가로 매각 가능 |

- 관리비채권 소멸시효는 3년(2005다65821). 3년 넘은 체납분은 다툴 여지.

## 5. 인도명령 — 누가, 누구에게, 언제 (제136조)
| 항목 | 내용 |
|---|---|
| 신청인 | 매수인. 상속인 등 일반승계인 가능, 매수인에게 산 사람(특별승계인)은 불가 → 소송 |
| 상대방 | 채무자·소유자·점유자. 매수인에게 대항할 권원이 있는 점유자 제외 |
| 기한 | 대금 완납 후 6개월 |
| 관할 | 경매를 진행한 집행법원(담당 경매계) |
| 심문 | 채무자·소유자 외 점유자는 심문. 권원 없음이 명백하거나 이미 심문했으면 생략 |
| 불복 | 즉시항고(고지 후 1주, 제15조). 항고만으로 집행 정지 안 됨 — 별도 정지결정 필요 |
| 누구 이름으로 | 현황조사서·전입세대열람에 나온 사람 모두. 모르는 점유자는 아는 이름 먼저 + 가처분 |

## 6. 명도 5단계
1. **협상** — 낙찰 당일부터. 점유자 파악(누구·몇 명·원하는 것·반응). 마감은 잔금일.
2. **내용증명** — 잔금 후. 인도 기한, 불응 시 인도명령·강제집행·비용 청구 예고.
3. **인도명령 + 점유이전금지가처분** — 잔금 당일 신청. 점유자가 바뀔 우려가 있으면 가처분 함께(민사집행법 제300조).
4. **강제집행 신청·계고** — 결정 정본·집행문·송달증명원으로 집행관사무소에 신청, 비용 예납. 계고장 부착이 협상의 마지막 지렛대.
5. **본집행** — 매수인(또는 대리인) 출석 필수(제258조②). 점유자 없으면 성년 2명 등 증인 참여(제6조). 짐은 채무자에게 인도, 없으면 보관 → 안 찾아가면 법원 허가로 매각(제258조③~⑥).

**협상 원칙**
| 원칙 | 내용 |
|---|---|
| 지렛대 먼저 | 인도명령·강제집행 절차와 비용을 사실대로 설명 |
| 이사비는 의무 아님 | 법적 지급 의무 없음. 주더라도 강제집행 예상 비용 이하에서 |
| 기한 고정 | 이사 날짜를 합의서에 못 박고, 열쇠 받는 날 지급 |
| 말은 기록으로 | 통화·문자 기록, 합의는 서면 |

**강제집행 비용(실무 예시, SBS Biz 2023 인터뷰 기준)**
| 항목 | 금액 |
|---|---|
| 노무비 | 인부 1인당 약 12만원, 33평형 약 12명 ≈ 150만원 |
| 운반 트럭 | 약 60만원 |
| 창고 보관 | 2~3개월 약 60만~90만원 |
| 합계 | 약 150만~300만원 (지역·짐 양·평형에 따라 차이 큼) |
- 매수인이 먼저 예납(제18조), 최종 부담은 채무자(제53조). 회수는 집행비용액확정결정 후 추가 집행. 정확한 금액은 관할 집행관사무소에 확인.

## 7. 서류 작성법
〔그림: 명도합의서 작성 예시 — 이사일, 이사비, 짐 처리, 관리비 정산, 위약 시 조치〕

| 구분 | 명도합의서 | 명도확인서 |
|---|---|---|
| 누가 | 매수인 ↔ 점유자 쌍방 서명 | 매수인 → 임차인에게 발급 |
| 왜 | 이사 날짜·조건 확정 | 임차인 배당금 수령에 필요(주택임대차보호법 제3조의2③) |
| 첨부 | 신분증 확인 | 매수인 인감증명서 |
| 언제 | 협상 타결 즉시 | **이사·열쇠 인도 확인 후**에만 |
| 법원 제출 | 안 함 | 임차인이 경매계에 제출 |

**명도합의서 칸**
| 칸 | 쓰는 법 |
|---|---|
| 부동산 표시 | 사건번호, 주소·동호수 |
| 당사자 | 매수인·점유자 성명·연락처(신분증 대조) |
| 인도일 | "○○년 ○월 ○일까지 짐을 모두 빼고 열쇠를 인도" |
| 이사비 | 금액, 지급 시점(열쇠 인도와 동시) |
| 짐 처리 | 남긴 짐은 포기한 것으로 보고 매수인이 처분 |
| 관리비·공과금 | 이사일까지 점유자 부담, 정산 방법 |
| 불이행 시 | 이사비 미지급, 강제집행·비용 청구 |

## 8. 리스크와 결과별 대응
〔그림: 판단 흐름도〕 점유자 파악 → 대항력? → (있음) 인수·소송 / (없음) 협상 → 합의? → (예) 합의서·이사·확인서 / (아니오) 인도명령 → 계고 → 본집행

| 리스크 | 영향 | 대응 |
|---|---|---|
| 대항력 있는 임차인 | 보증금 인수, 인도명령 불가 | 입찰 전 권리분석. 배당표 확정 후 인도 |
| 유치권 주장 | 소송 가능 | 점유 시작일 vs 압류일 비교, 판례 확인 |
| 점유자 변경 | 집행 불능 | 점유이전금지가처분 |
| 연락두절·폐문부재 | 송달 지연 1~2개월 | 특별·공시송달, 증인 참여 집행 |
| 짐 남김 | 보관비·매각까지 수개월 | 합의서에 포기 문구, 법원 허가 매각 |
| 미납관리비 | 공용부분 매수인 부담 | 낙찰 당일 확인, 연체료·3년 경과분 제외 협상 |
| 6개월 경과 | 인도명령 불가 | 명도소송(7~8개월 이상) |

## 9. 체크리스트
- 낙찰 당일: 관리사무소 미납관리비(공용·전용·연체료 구분), 세대 방문·메모, 현황조사서·전입세대열람으로 점유자 이름 확인.
- 잔금 전: 협상 마감일 = 잔금일, 이사비 상한(강제집행 예상 비용) 정하기, 합의서 양식 준비.
- 잔금 날: 인도명령 신청, 필요 시 점유이전금지가처분, 6개월 기한 메모.
- 결정 후: 송달 확인, 집행문·송달증명원 발급, 집행관사무소 신청·예납.
- 이사 날: 짐·열쇠 확인 후 이사비 지급, 그다음 명도확인서·인감증명서 교부, 계량기·관리비 정산.

## 10. 자주 묻는 질문
- 이사비를 꼭 줘야 하나요? → 법적 의무 없음. 강제집행 비용보다 싸면 시간을 사는 선택.
- 문 따고 들어가도 되나요? → 안 됨. 주거침입·재물손괴 위험. 강제집행으로만.
- 점유자가 즉시항고하면 멈추나요? → 항고만으로는 정지 안 됨. 별도 집행정지결정이 있어야 멈춤.
- 6개월을 넘기면? → 인도명령 불가, 명도소송.
- 명도확인서는 언제 주나요? → 이사·열쇠 인도를 확인한 뒤. 먼저 주면 지렛대가 사라짐.
