# MANUAL 08 · 입찰서류, 봉투 두 개면 끝 — 원고 v2 (검토·보강본)

> 바탕: VS Code 원고(카페 「경매 입찰서류 작성법」 1~4탄 정리) + 재검증. 디자인 컨셉: **작은 봉투(매수신청보증금봉투) + 큰 봉투(입찰봉투)**. 기준 2026. 11. 18.
> 페이지: web/manual/bid.html · 태그 필수 · 참고 표기는 '골든보이 마이턴 카페' 한 줄만

## VS Code 원고에서 고친 것
| 항목 | 원고 | 고침 |
|---|---|---|

## 00 요약
- 내는 것은 셋: **기일입찰표(종이 한 장)** + **작은 봉투(보증금)** → 둘 다 **큰 봉투(입찰봉투)** 에 넣어 집행관에게.
- 보증금: 최저매각가격의 10%가 원칙. 재매각 등은 법원이 달리 정함 → 공고 금액. 1원이라도 모자라면 무효.
- 입찰가격: 고치면 무효, 새 용지. '0' 하나 더 쓰면 10배.
- 처음이면 전날 집에서 다 써 간다.

## 01 상황별 준비물
| 상황 | 입찰표 | 더 내는 서류 | 챙길 것 |
|---|---|---|---|
| 본인 | 본인란 | — | 신분증 · 도장 · 보증금 |
| 대리 | 본인란 + 대리인란 | 위임장(입찰표 뒷면, 본인 인감 날인) + 본인 인감증명서(3개월 이내) | 대리인 신분증 · 도장 · 보증금 |
| 공동 | 본인란에 "별첨 공동입찰자목록 기재와 같음" | 공동입찰신고서 + 공동입찰자목록(지분) · 안 온 사람 위임장 · 인감증명서 | 참석자 신분증 · 도장 · 보증금 |
| 공동+대리 | 위 + 대리인란 | 신고서 · 목록 + 각자 위임장 · 인감증명서 | 대리인 신분증 · 도장 · 보증금 |

## 02 기일입찰표 (2026. 11. 2. 새 양식)
칸 순서: 법원·집행관 귀하 / 입찰기일 / 사건번호 · 물건번호(여럿이면 꼭) / 본인(성명·전화·주민번호·주소) / 대리인(관계 포함) / 보증 제공방법 ☑ / 보증금액 / 입찰가격(새 양식은 위아래로 크게) / '보증을 반환받았습니다' 서명(떨어진 뒤에만).
- 금액은 오른쪽 '일' 칸부터 거꾸로 채우고, 다 쓴 뒤 자릿수를 소리 내어 읽는다.
- 입찰가격은 정액으로. 고쳐 쓰면 무효 → 여분 용지.
- 물건마다 입찰표 따로. 낸 뒤엔 취소·변경·교환 불가(민사집행규칙 제62조).

## 03 작은 봉투 — 매수신청보증금봉투
- 겉: 사건번호 · 물건번호 · 제출자 이름 (인). 뒷면 봉하는 곳에도 날인.
- 안: 자기앞수표 1장(금액 딱 맞게). 넘치는 건 괜찮고 모자라면 무효(20원 부족도 무효 — 대법원 2007마911).
- 금액: 원칙 최저가 10%(규칙 제63조), 재매각은 20%가 흔함 → 공고 · 매각물건명세서 금액.
- 수단: 현금 · 자기앞수표 · 지급보증위탁계약 증명서(보증보험증권) 중 하나(규칙 제64조).

## 04 큰 봉투 — 입찰봉투
- 겉: 사건번호 · 물건번호 · 제출자 본인 (인) · 대리인 (인).
- 넣는 순서: 기일입찰표 + 작은 봉투 → 큰 봉투. 봉하는 방법은 집행관 안내대로.
- 제출: 집행관에게 신분증 → 봉투에 날인 받고 위쪽 **입찰자용 수취증**을 떼어 받음 → 입찰함. 수취증은 떨어졌을 때 보증금 찾는 표.

## 05 대리 · 공동 입찰 서류
- 위임장: 입찰표 뒷면. 대리인 인적사항 · 사건번호 · 위임 내용 · 본인 인감 날인. 인감증명서 인영과 같아야 함.
- 공동입찰: 신고서 + 목록에 **각자 지분**을 분명히(규칙 제62조). 신고서와 입찰표 사이 전원 간인.
- 법인: 법인등기사항증명서 + 법인인감증명서(3개월 이내), 대표자가 아니면 위임장.

## 06 당일 흐름과 결과
전날(수표 · 작성) → 도착 · 게시판(변경 · 취하 · 연기 확인) → 입찰 개시 · 작성 → 제출(신분증 · 날인 · 수취증) → 마감 → 개찰(사건 순서) → 결과
- 최고가: 보증금 영수증 → 매각허가결정 → 잔금.
- 차순위 신고: 최고가 − 보증금보다 높게 썼을 때만, 매각기일 끝나기 전에(민사집행법 제114조).
- 떨어짐: 수취증 + 신분증 → 그 자리에서 보증금 반환, 입찰표 반환란에 서명(제115조③).

## 07 무효가 되는 실수
보증금 부족 · 입찰가격 고침 · 물건번호 빠짐(개별매각) · 위임장 인감 날인 빠짐 · 인감증명서 없음 · 공동입찰 지분 없음 · 법인 자격서류 없음. → 무효여도 보증금은 돌려받음.
