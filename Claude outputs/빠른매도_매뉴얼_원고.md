# 빨리 파는 매도 매뉴얼 — 원고(목차·상세)

> 바탕: 유튜브 쇼츠 「부동산 빨리 매도하는 법」(경장인, 2025. 10. 20.)의 5가지 팁
> 보강: 공인중개사법(중개보수·전속중개), 지자체 중개보수 요율표, NAR 2025 홈스테이징 보고서
> 〔사용자 의견 반영 자리 — 말씀 주시면 해당 장에 넣음〕

## 영상 5가지 팁과 현실 점검
| 영상 팁 | 맞는 점 | 바로잡을 점 / 보강 |
|---|---|---|
| 1. 중개수수료 두 배 | 중개사가 먼저 움직이게 하는 건 맞음 | **법정 상한을 넘는 보수는 명목 불문 중개사가 받으면 불법**(1년 이하 징역·1천만원 이하 벌금, 등록취소). → 상한요율까지 꽉 채워 주겠다고 약속하는 게 합법적 최대치 |
| 2. 공실 상태 | 넓어 보이고 아무 때나 보여줄 수 있음 | 공실 기간의 관리비·이자 비용 계산. 비번·열쇠는 중개사 동행 원칙 |
| 3. 디퓨저·슬리퍼 | 몇천 원으로 첫인상 개선 | 환기·청소·전구 교체가 먼저. NAR 2025: 매도 측 중개인 49% "연출이 매도 기간을 줄였다", 매수자에게 중요한 곳은 거실·안방·주방 |
| 4. 여러 중개사 등록 | 노출이 넓어짐(일반중개계약) | **가격·자료를 통일**해야 함. 한 곳에 맡기는 전속중개(3개월, 정보망 공개, 2주 1회 보고)와 비교해 선택 |
| 5. 홍보 자료 | 적극적인 매도인으로 보임 | 사실만, 과장 금지. 사진·평면·수리 내역·관리비·입주 가능일 1장으로 |

## 목차 (5장)
0. 요약
1. 가격·준비 — 팔리는 호가부터
2. 중개사 움직이기 — 수수료와 등록 방식
3. 집 보여주기 — 공실·연출
4. 홍보 자료 — 1장으로
5. 체크리스트
(참고)

## 0. 요약
| 원칙 | 내용 |
|---|---|
| 가격 | 실거래가·급매가에 맞춘 호가. 첫 2~3주 반응이 가장 중요 |
| 중개사 | 상한요율 약속 + 여러 곳에 같은 가격·같은 자료 |
| 보여주기 | 공실·청소·환기·조명, 디퓨저·슬리퍼 |
| 자료 | 사진·장점·수리 내역 1장, 중개사에게 배포 |
| 세금 | 매매사업자면 사업자 명의 계약, 과세 물건 '부가세 별도', 2개월 안 예정신고 |

## 1. 가격·준비
- 국토부 실거래가, 같은 단지 매물 호가, 중개사에게 '바로 팔리는 가격' 확인.
- 호가는 처음부터 팔리는 선에서. 오래 걸린 매물은 '안 팔리는 집'으로 보임.
- 서류: 등기부, 건축물대장, 관리비 내역, 수리 영수증(매매사업자 경비 증빙 겸).
- 매매사업자: 사업자 명의 계약, 과세 물건(85㎡ 초과·오피스텔·상가)은 '부가가치세 별도' 문구.

## 2. 중개사 움직이기
**중개보수 — 합법적 최대치**
| 주택 매매 금액 | 상한요율 | 한도액 |
|---|---|---|
| 5천만원 미만 | 0.6% | 25만원 |
| 5천만~2억 미만 | 0.5% | 80만원 |
| 2억~9억 미만 | 0.4% | 없음 |
| 9억~12억 미만 | 0.5% | 없음 |
| 12억~15억 미만 | 0.6% | 없음 |
| 15억 이상 | 0.7% | 없음 |
- 상가·토지 0.9% 이내, 오피스텔(85㎡ 이하·부엌·욕실 등) 0.5%.
- 상한 안에서 협의하는 구조라 깎는 경우가 많음 → "상한까지 드리겠다"는 약속이 곧 인센티브.
- 상한을 넘는 사례비·컨설팅비 등은 중개사가 받으면 불법(명목 불문) — 매도인도 제안하지 않기.

**등록 방식 비교**
| 항목 | 여러 곳(일반중개) | 한 곳(전속중개) |
|---|---|---|
| 노출 | 넓음 | 정보망·일간지 공개(7일 안) |
| 관리 | 매도인이 가격·자료 통일 관리 | 중개사가 2주 1회 문서 보고 |
| 기간 | 제한 없음 | 원칙 3개월 |
| 주의 | 가격 혼선, 중복 광고 | 다른 곳 거래 시 위약금(중개보수 상당) |
| 맞는 경우 | 빨리 넓게 알릴 때 | 믿을 만한 1곳에 맡길 때 |

## 3. 집 보여주기
- 공실: 명도 후 짐 정리·청소. 관리비·이자 비용과 비교.
- 연출: 환기 → 청소(화장실·주방) → 전구 교체 → 디퓨저·슬리퍼.
- 중요 공간: 거실·안방·주방(NAR 2025).
- 방문: 중개사 동행, 비번은 수시 변경. 매매사업자는 재고 주택에 전입 금지.

## 4. 홍보 자료
- 1장 구성: 대표 사진 6~10장, 평면, 장점 3가지(교통·학군·뷰 등), 수리 내역, 관리비, 입주 가능일, 연락처.
- 모든 중개사에게 같은 자료·같은 가격으로.
- 사실만. 과장하면 계약 후 분쟁.

## 5. 체크리스트(글자형)
- 내놓기 전: 실거래가·호가 확인, 서류, 수리·청소, 사진
- 내놓을 때: 중개사 여러 곳(또는 전속 1곳), 같은 가격·자료, 상한요율 약속
- 보여줄 때: 환기·조명·디퓨저·슬리퍼, 중개사 동행
- 계약 때: 사업자 명의, 부가세 별도(과세 물건), 잔금일·명도 조건
- 판 뒤: 2개월 안 예정신고
