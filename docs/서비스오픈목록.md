# 서비스 오픈 때 열 것

정식 서비스를 시작할 때 켜거나 채울 것들이다. 지금은 숨겨 두었거나(주석), 저장만 하고 아직 쓰지 않거나, 임시 값으로 두었다.
하나 열 때마다 이 목록에서 지우거나 '열었음'과 날짜를 적는다.

처음 적은 날 2026-11-02

## 1. 휴대폰 문자 인증
- 지금: 회원가입의 [인증요청] 단추를 숨겼다. 번호는 받아서 그대로 저장한다(인증하지 않은 번호).
- 여는 곳
  - [src/pages/SignupPage.vue](../src/pages/SignupPage.vue): 템플릿의 `인증요청` 단추 주석, 스크립트의 `onVerifyPhone` 주석을 푼다.
- 할 일
  - 문자 발송 서비스를 고른다(Firebase 휴대폰 인증 또는 문자 업체).
  - 인증번호 입력 칸을 붙이고, 인증한 번호인지(`phoneVerified` 등)를 저장한다.
  - firestore.rules 의 users 칸 목록에 그 칸을 더한다. 단, 본인이 직접 '인증됨'으로 적을 수 없게 서버가 적는다.

## 2. 가입한 사람이 바로 쓰게 하기(허용 목록 풀기) — 열었음 2026-11-02
- 사용자 요청('다 열어줘')으로 로그인한 사람이면 누구나 쓸 수 있게 열었다.
- 스위치
  - 앱: [src/services/accessControl.ts](../src/services/accessControl.ts) 의 `OPEN_TO_ALL = true`
  - DB: [firestore.rules](../firestore.rules) 의 `isAllowedUser()` 가 `request.auth != null`. 예전 허용 목록 줄은 주석으로 남겨 두었다
- 되돌리기: `OPEN_TO_ALL = false`, 규칙의 주석 줄을 살린 뒤 함께 배포한다.
- 그대로인 것: 운영자(게시판 글 지우기 · 집 PC 수집 도우미)는 여전히 운영자 2계정(`ADMIN_EMAILS` · 규칙 `isAdmin()`)만이다.
- 열면서 남은 걱정(서비스 오픈 전에 손볼 것)
  - 공용 캐시: `cache*` 컬렉션(실거래 · 세대수 · 공시가격 등)을 가입자 누구나 쓸 수 있다. 나쁜 뜻으로 틀린 값을 적으면 모두에게 보인다. 서버만 쓰게 바꾸는 것을 검토한다.
  - 무료 한도: Firestore 무료(Spark)는 하루 읽기 5만 · 쓰기 2만이다. 넘으면 그날은 모두 멈춘다. 사람이 늘기 전에 Blaze 로 바꾼다.
  - 요금: 웹은 결제 전이라 모두 유료 회원 화면이다(4번).
  - 계정 문서: users/{uid} 는 본인이 모든 칸을 적을 수 있다. 무료이용 · 포인트는 여기 두지 말고 본인이 못 적는 곳에 둔다(3번).

## 3. 가입 혜택 지급 — 3일 무료이용권 · 1,000P
- 지금: 가입 화면 · 무료체험 안내에는 적혀 있지만 실제로 주는 곳(저장 칸)이 없다.
  - 값: [src/services/billingPlans.ts](../src/services/billingPlans.ts) 의 `TRIAL_DAYS` · `WELCOME_POINT`

  - 본인이 고칠 수 없게 한다. 지금은 모두에게 열려 있어(2번) users/{uid} 의 모든 칸을 본인이 적을 수 있으니, 본인이 쓰기 못하는 따로 된 컬렉션에 둔다.
  - '계정당 1회'를 지킨다(탈퇴 뒤 다시 가입 등).

## 3-1. 포인트 관리(보유 · 적립 · 차감 · 내역 · 등급)
- 지금: 화면만 있다. 저장하는 곳이 없다.
  - 보유포인트: 늘 0 P 로 적어 둔 값이다.
  - 포인트내역: 빈 목록이다.
  - 등급: 결제 누계가 없어 모두 첫 등급이다.
  - 위치: [src/pages/PointHistoryPage.vue](../src/pages/PointHistoryPage.vue) 의 `myPoint = 0` · `paidTotal = 0` · `rows = []`, 웹 펼침 메뉴 '보유포인트 0 P'([web/pages/selected.src.html](../web/pages/selected.src.html))
- 숨겨 둔 화면(2026-11-02, 지우지 않고 숨김) — 포인트를 붙이면 둘 다 true 로
  - 웹 마이페이지 › 내 정보 맨 위 '회원등급' · '누적 포인트' 칸, 계정관리 '포인트내역' 카드 — [src/components/MyPageCards.vue](../src/components/MyPageCards.vue) 의 `SHOW_GRADE_POINT`
  - 웹 마이페이지 하위 탭 '포인트', 위 펼침 메뉴의 '포인트', 이름 메뉴의 '보유포인트' · 등급 배지 · '포인트' 단추 — [web/pages/selected.src.html](../web/pages/selected.src.html) 의 `SHOW_POINTS`
- 할 일

  - 가입 축하 1,000P(3번), 결제 적립 · 사용(4번)과 같이 붙인다.
  - 등급은 결제 누계로 정한다.
