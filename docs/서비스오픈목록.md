# 서비스 오픈 때 열 것

정식 서비스를 시작할 때 켜거나 채울 것들이다. 지금은 숨겨 두었거나(주석), 저장만 하고 아직 쓰지 않거나, 임시 값으로 두었다.
하나 열 때마다 이 목록에서 지우거나 '열었음'과 날짜를 적는다.

처음 적은 날 2026-11-02

## 1. 휴대폰 문자 인증
- 지금: 회원가입의 [인증요청] 단추를 숨겼다. 번호는 받아서 그대로 저장한다(인증하지 않은 번호).
- 여는 곳
  - [src/pages/SignupPage.vue](../src/pages/SignupPage.vue): 템플릿의 `인증요청` 단추 주석, 스크립트의 `onVerifyPhone` 주석을 푼다.
- 할 일
  - 문자 발송 서비스를 고른다(Firebase 휴대폰 인증 또는 문자 업체).
  - 인증번호 입력 칸을 붙이고, 인증한 번호인지(`phoneVerified` 등)를 저장한다.
  - firestore.rules 의 users 칸 목록에 그 칸을 더한다. 단, 본인이 직접 '인증됨'으로 적을 수 없게 서버가 적는다.

## 2. 가입한 사람이 바로 쓰게 하기(허용 목록 풀기)
- 지금: 앱 · 웹은 정해 둔 3개 계정만 쓸 수 있다. 새로 가입한 사람은 가입 · 가입 정보 저장까지는 되지만, 로그인하면 '사용 권한 없음'이 뜬다.
- 여는 곳(둘을 같이 고쳐 배포)
  - [src/services/accessControl.ts](../src/services/accessControl.ts): `ALLOWED_EMAILS` · `isAllowedEmail`
  - [firestore.rules](../firestore.rules): `isAllowedUser()`
- 할 일: 허용 목록 대신 '이용 기간이 남은 회원'(무료체험 · 결제)으로 막도록 바꾼다(아래 3 · 4와 함께).

## 3. 가입 혜택 지급 — 3일 무료이용권 · 1,000P
- 지금: 가입 화면 · 무료체험 안내에는 적혀 있지만 실제로 주는 곳(저장 칸)이 없다.
  - 값: [src/services/billingPlans.ts](../src/services/billingPlans.ts) 의 `TRIAL_DAYS` · `WELCOME_POINT`
- 할 일
  - 서버(Cloud Functions 등)가 가입할 때 무료이용 끝나는 날 · 포인트를 적는다.
  - 본인이 고칠 수 없게 한다. 지금 firestore.rules 는 새 가입자가 자기 문서에 적을 수 있는 칸을 가입 정보 · 내 정보로만 묶어 두었다(무료이용 · 포인트 칸은 막힘).
  - '계정당 1회'를 지킨다(탈퇴 뒤 다시 가입 등).

## 4. 결제(PG)와 이용 기간
- 지금: 웹은 모두 유료 회원으로 본다. 임시로 브라우저의 `myturn.plan` 이 'free' 일 때만 무료 화면이다.
  - 위치: [web/pages/selected.src.html](../web/pages/selected.src.html) 의 `PAID`
- 할 일
  - PG를 붙인다.
  - 이용권 끝나는 날을 계정에 저장하고, `PAID` 를 그 날짜로 계산하게 바꾼다.
  - 같이 꺼낼 것: 푸시 알림(FCM) 토큰 저장, 구독 끝나는 날 알림.

## 5. 추천코드
- 지금: 웹 가입에서 코드를 받아 `users/{uid}.referralCode` 에 저장만 한다.
  - 화면의 '코드에 따라 무료 이용 기간이 자동 적용됩니다'는 아직 동작하지 않는다.
- 할 일
  - 코드 표(코드 → 무료 일수)를 만든다.
  - 가입할 때 서버가 확인해 무료이용 끝나는 날에 더한다(3과 같이).

## 6. 아이디 중복확인
- 지금: Firebase 의 '메일 존재 숨기기' 설정 때문에 대개 '쓸 수 있어 보입니다'로만 나온다. 진짜 중복은 가입할 때 걸린다.
- 할 일(필요하면): 서버에서 확인하는 중복확인으로 바꾼다.
