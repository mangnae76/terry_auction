## 1. 오늘 만든 것 — 관리자 분석 도구 (웹 전용)

`/admin` 아래 네 화면이다. 앱(손전화)이 아니라 **웹에서만** 쓴다.

| 화면 | 길 | 하는 일 |
|---|---|---|
| 분석 도구 첫 화면 | `/admin` | 카드 여섯 장, 세 묶음 |
| 실거래 분석 | `/admin/region-demand` | 시군구의 읍면동별 거래량·평균가·수요공급 지표 |
| 실거래가 조건 분석 | `/admin/dong-trades` | 한 시군구의 거래를 줄 단위로 늘어놓고 칸마다 걸러내기 |
| 경매지번 공동주택가 및 실거래가 | `/admin/case-trades` | 주소 한 줄로 공동주택가 + 그 지번의 매매·전세·월세 |

**services (화면을 모른다 — 분석 도구를 앱과 갈라도 따라간다)**

- `addressLookup.ts` — 주소 → 지역·지번·호수·건물 동·공동주택가
- `caseTradeAnalysis.ts` — 주소 → 그 지번의 실거래 (매매·전세·월세)
- `regionCodes.ts` — 시도·시군구 LAWD 코드 (시장정보 조건검색과 같이 쓴다)
- `adminSnapshots.ts` — 분석을 값 그대로 박제 (Firestore `adminSnapshots`)
- `composables/useColumnFilters.ts` + `components/ColumnFilterPanel.vue` —
  엑셀 자동 필터 꼴의 칸별 걸러내기. 조건 분석·경매지번 두 화면이 같이 쓴다

### 알아 둘 것

- **국토부는 '시군구 + 한 달'씩만 준다.** 그래서 12개월이면 12번, 10년치
  매매+전월세면 240번 부른다. 받은 것은 `cachePlaceHistory` 등에 담아 두고
  앱과 나눠 쓴다.
- **공동주택가격(브이월드)은 개발 환경에서 안 나온다.** 인증키가 클라우드플레어
  워커 비밀값으로만 있어서다. `vite.config.ts` 에 `/api-vworld` 를 배포된 워커로
  넘기는 통로를 뚫어 뒀으니, `.env` 의 `VITE_API_BASE` 가 있으면 개발에서도 보인다.
- **지번은 카카오가 준 값을 쓴다.** 도로명 주소를 쳐도 지번이 나온다
  (`ResolvedRegion.jibun`). 사용자가 친 글자에서 긁지 않는다.
- **공시가격은 동+호로 맞춘다.** 한 지번에 동이 여럿이면 호수만으로는 못 가린다.

## 2. 오늘 고친 것 — 앱 쪽

- **세금관리를 자금관리 안으로** 넣었다. 자금관리에 `세금신고` 탭이 생기고,
  `TaxPage` 에 `embedded` 를 주어 제 머리글·하단 메뉴를 그리지 않게 했다.
  하단 메뉴는 다섯 개(선정물건·임장경로·자금관리·시장정보·더보기).
  `/tax` 로 바로 열면 전처럼 한 장으로 선다.
- **자금관리 네 표**의 칸·맞춤·이름을 손봤다 (아래 3번 참고).
- **손품+현장**: 전세 평당가 칸을 더하고 '평단가'를 '매매 평당가'로,
  예상 수익 분석의 '낙찰·매도'를 '낙찰일·매도일'로, 전세가 비율 기본값을 126%로.
- **배포 뒤 묵은 조각 문제**: 늦게 불러오는 화면(자금관리·세금관리·더보기·관리자)이
  새 배포 뒤 열리지 않던 것을 `router.onError` + `vite:preloadError` 로 잡아
  한 번만 새로 읽게 했다 (`src/router/index.ts`).

## 3. 자금관리(사업자금관리) — 지금 모양

탭: `자금입출금 · 사업지출 · 유류&식대 · 물품구매 · 세금신고`
제목·탭·도구줄은 붙박이, 아래만 구른다 (선정물건과 같은 짜임).

| 표 | 칸 |
|---|---|
| 자금입출금 | 일자 · 명세 · 입출금 · 개인 자금 · 비고 |
| 사업지출 | 결제일 · 물건 · 사용구분 · 명세 · 비용(VAT포함) · 비고 |
| 유류&식대 | 사용일 · 사용처 · 사용구분 · 비용 · 사용카드 · 비고 |
| 물품구매 | 사용일 · 사용구분 · 상세내역 · 수량 · 단가 · 계 · 합계(VAT) · 구매업체 · 카드 · 비고 |

- 맞춤 규칙: 금액 칸만 오른쪽(자금입출금의 개인 자금), 나머지는 가운데.
  긴 글 칸은 `colgroup` 으로 폭을 못 박았다.
- 알약 색: **입금 분홍/빨강, 출금 하늘/파랑, 사용구분 회색**.
- 날짜는 표에서 앞의 '20' 을 뗀다 (`26-10-14`). 엑셀에는 네 자리로 넣는다.
- 항목 편집 창은 **날짜가 첫 칸**이고, 돈 칸은 적는 동안에도 쉼표가 보인다
  (`FormattedNumberInput` + `live-group`).
- **표에서 감춘 값도 자료에는 남아 있다** — 유류&식대의 지역·사용자,
  물품구매의 물건·배송비 등. 입력 칸만 뺀 것이라 옛 자료는 그대로다.

## 5. 함정 — 꼭 읽을 것

- **관리자 화면은 로그인을 받는다.** 머리 없는 브라우저로 확인하려면
  `src/router/index.ts` 의 세 줄에 `meta: { public: true }` 를 잠깐 넣고
  **커밋 전에 반드시 되돌린다**. (`grep -c "meta: { public: true }"` 가 1이어야
  한다 — 로그인 화면 하나뿐)
- **빌드 확인은 종료 코드로 본다.** `npm run build | grep ...` 는 오류가 나도
  grep 이 성공해서 파이프라인이 이어진다. 오늘 한 번 그렇게 깨진 채로 커밋했다.
  `npm run build > build.log 2>&1; echo $?` 로 확인할 것.
- **개발 서버는 `npx vite --port 5199`** 로 띄운다. `vite preview` 에는 API
  통로가 없어 국토부·카카오 호출이 모두 막힌다.
- **비밀값**: 저장소가 공개다. 밀기 전에
  `git diff --cached | grep -niE "ghp_|github_pat|AIza|serviceKey=|-----BEGIN|password|secret"`
  를 돌린다. 브이월드 키는 **워커 비밀값으로만** 둔다.
- **되돌리기**: 오늘 작업은 커밋 단위가 잘게 끊겨 있다. 배치만 바꾼 커밋
  (`지표 칸을 세 줄로` 등)은 `git revert <해시>` 한 번이면 그대로 돌아간다.
